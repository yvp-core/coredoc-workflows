# Support

Use [GitHub Discussions](https://github.com/yvp-core/coredoc-workflows/discussions)
for usage questions and ideas, and
[GitHub Issues](https://github.com/yvp-core/coredoc-workflows/issues) for
reproducible defects.

Security reports belong in
[private vulnerability reporting](https://github.com/yvp-core/coredoc-workflows/security/advisories/new),
not in public issues.

The currently supported runtime target is macOS 13 or later on Apple silicon.
Browser QA also requires an installed Chrome-compatible browser. Coredoc
Desktop and the Coredoc MCP server are optional unless the requested workflow
explicitly needs their functionality.
